# «Web бағдарламалау» — электрондық кітап

«Учебно-методические комплексы дисциплин.pdf» файлының (153 бет) электрондық кітап нұсқасы.
Бірде-бір бет түсіп қалмаған: әр бет PDF-тен сол қалпында сурет болып алынған.

## Қалай ашу керек

`index.html` файлын екі рет бас → мұқабадағы **«Кітапты ашу»** батырмасын бас.

⚠️ Парақ аудару кітапханасы интернеттен (cdn.jsdelivr.net) жүктеледі, сондықтан кітапты ашқанда интернет керек.

## Не істей алады

| Мүмкіндік | Қалай |
|-----------|-------|
| Бетті аудару | парақтың бұрышын тышқанмен ұстап тарту (шынайы кітаптай); бетті басу; `←` `→` пернелері; телефонда саусақпен сырғыту |
| Аудару анимациясы | қағаз парақ иіліп, бүктеліп аударылады, бүгілген жеріне көлеңке түседі; мұқабалар қатты картон сияқты ашылады; тышқанды бұрышқа апарса, парақ сәл көтеріледі |
| Дыбыс | әр аударғанда қағаздың сыбдыры естіледі (3 түрлі дыбыс); дыбыс батырмасымен өшіруге болады |
| Мазмұны | кітаптың бірінші бетінде (1-беттің сол жағында) және жоғарғы «Мазмұны» батырмасында; тақырыпты басса — сол бетке аударылады |
| Іздеу | «Іздеу» батырмасы — сөзді жазсаң, қай беттерде кездесетінін көрсетеді |
| Беттер | «Беттер» батырмасы — 153 беттің кішкентай суреттері, басқанда сол бетке өтеді |
| Үлкейту | «Үлкейту» батырмасы немесе бетті екі рет басу — бет үлкен болып ашылады (жалпақ кестелер, 6–12 беттер, толық енімен) |
| Бет нөмірі | төменгі жолға нөмірді жазып `Enter` бассаң, сол бетке өтеді; жүгірткіні сүйреуге де болады |
| Есте сақтау | кітапты қайта ашқанда соңғы оқыған бетіңнен басталады |

## Кодтың қарапайым түсіндірмесі

**Кітап қалай аударылады.** Шынайы қағаз сияқты иілетін парақты **StPageFlip** деген ашық кітапхана
(MIT лицензиясы) салады — `index.html` оны интернеттен қосады:

```js
pageFlip = new St.PageFlip(flipbook, {
  width: size.w,          // бір беттің ені
  height: size.h,         // бір беттің биіктігі
  showCover: true,        // бірінші және соңғы бет — қатты мұқаба
  flippingTime: 900       // бір парақ 0,9 секундта аударылады
});
pageFlip.loadFromHTML(pages);
```

`pages` — 156 парақ: мұқаба, «Мазмұны», PDF-тің 153 беті және артқы мұқаба. Кітапхана парақтың
бұрышын тышқанның артынан ілестіріп иеді, бүктелген сызықтың бойына көлеңке салады.

Кітап өте ауыр болмауы үшін суреттер бірден жүктелмейді: `loadNear()` тек ашық тұрған беттің
алды-артындағы 10 бетті жүктейді.

**Дыбыс.** `new Audio('sounds/flip1.wav')` — дыбыс файлын ойнатқыш. Парақ аударыла бастағанда
(`changeState` → `flipping`) үшеуінің
біреуі кездейсоқ таңдалып ойнайды, сондықтан дыбыс біркелкі болып жалықтырмайды.

**Іздеу.** `book-data.js` ішінде әр беттің мәтіні сақталған. Сөз жазылғанда код 153 мәтінді
аралап, сөз кездескен беттерді тізім қылып шығарады.

```bash
swift tools/render_pages.swift "Учебно-методические комплексы дисциплин.pdf" .
python3 tools/convert_images.py
python3 tools/make_data.py
python3 tools/make_flip_sounds.py
```
